# Tacto 1.0 제한 베타 참여 안내

이 베타는 정식 출시 전 실제 사용 문제를 찾는 과정입니다. 성공을 보장하거나
설치·권한·복구 검증을 대신하지 않습니다. **최소 5명이 3일 동안 사용하며,
각자 실제 작업 3개 이상을 수행**해야 합니다. 반복 실행 횟수를 참여자 수로
세지 않고, 실패한 시도도 모두 기록합니다.

## 시작 전

담당자가 제공한 RC의 태그·DMG SHA256을 확인하고 기록합니다.
현재 후보는 `v1.0.0-rc.4`(DMG SHA256 `62a3da859be6077b96886d3a23458cd90b631ccc180e1dddb8f573ce55cc2a0c`)이며 정식 안정 버전이 아닙니다.
검증 중 앱이 바뀌면 담당자에게 알리고 새 후보로 결과를 구분합니다.

rc.3에서 실패한 Finder 행 선택을 개선해, 이 후보의 다중 창·Finder 전면 조건에서 실제 앱 작업 60건을 통과했습니다.
복구 시나리오는 두 실행으로 나누어 12건의 성공을 확인했습니다. 첫 실행에서 입력 전 읽기 전용 Finder 관찰이 30초 제한을 초과한 기록 1건도 보존했으며, 무중단 12/12 통과를 뜻하지 않습니다.
자세한 범위와 남은 검증은 [rc.4 검증 결과](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.4)를 확인합니다.
새 사용자 설치·권한 재부여·제한 베타는 사람이 확인해야 하며, 자동 검사 성공만으로 정식 안정 버전을 승인하지 않습니다.

DMG에서 Tacto를 Applications로 옮긴 뒤 시작 안내에 따라 연결합니다.
Mac·macOS·대상 앱·에이전트와 모델 버전을 기록합니다. 기존 사용자와 새
사용자를 구분하고, 설치 실패나 권한 안내가 이해되지 않는 경우도 보고합니다.

## 3일 동안 할 일

자신이 실제로 맡기려는 작업을 최소 3개 고릅니다. 예를 들어 시험용 폴더의
파일 정리, 공개 웹페이지에서 정보 확인, 소유한 문서의 편집·저장입니다.
처음 작성한 Flow를 입력값만 바꿔 재사용하는 작업도 포함하면 좋습니다.

각 시도에 다음을 기록합니다.

| 항목 | 기록할 내용 |
|---|---|
| 참여자 | 담당자가 부여한 익명 ID |
| 환경 | 후보 태그·DMG SHA256·OS·앱·에이전트·모델 버전 |
| 작업 | 요청한 목표, 처음 실행인지 Flow 재사용인지 |
| 결과 | 성공·실패·불확실, 실제로 확인한 최종 상태 |
| 시간 | 시작·종료 시각 또는 대략적인 소요 시간 |
| 개입 | 창을 앞으로 가져오기, 직접 입력, 재시도 등 사람이 도운 내용 |
| 오류 | 실패 단계·오류 이름·실행 기록 ID와 재현 조건 |

실패 후 이미 저장·전송됐는지 먼저 확인합니다. 불확실한 결과를 성공으로
보고하거나 실패 기록을 지우지 않습니다. 원치 않는 대상 조작·중복 실행·
데이터 손상·정보 노출·설치 불가가 있으면 해당 작업을 멈추고 담당자에게
재현 조건을 전달합니다.

## 실행 기록 공유

Tacto 앱의 실행 기록에서 해당 시도를 확인합니다. 계정명·문서 본문·개인
경로·화면 캡처가 들어갈 수 있으므로 공유할 부분을 먼저 검토합니다.
보고서에는 익명 ID와 오류·단계·기록 ID를 우선 제공하고, 필요한 원본은
담당자가 정한 비공개 경로로만 전달합니다.

## 완료 판단

담당자는 5명의 3일 사용과 각자 3개 이상 작업, 전체 실패 기록을 확인합니다.
출시를 막는 결함이 없어야 베타 항목을 통과로 바꿀 수 있습니다. 자동 검사나
담당자의 반복 실행으로 이 조건을 대체하지 않습니다. 새 사용자 설치와 권한
복구 3회는 [출시 기준](release-readiness.md)의 별도 항목으로 확인합니다.
