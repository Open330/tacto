# Tacto 1.0 제한 베타 참여 안내

이 베타는 정식 출시 전 실제 사용 문제를 찾는 과정입니다. 성공을 보장하거나
설치·권한·복구 검증을 대신하지 않습니다. **최소 5명이 3일 동안 사용하며,
각자 실제 작업 3개 이상을 수행**해야 합니다. 반복 실행 횟수를 참여자 수로
세지 않고, 실패한 시도도 모두 기록합니다.

## 시작 전

담당자가 제공한 RC의 태그·DMG SHA256을 확인하고 기록합니다.
현재 후보는 `v1.0.0-rc.11`(DMG SHA256 `5c20cd3be5e5237086cf596cc89f2988627e7ccba04de1287a38d958c9cb5b05`)이며 정식 안정 버전이 아닙니다. 앱 설정에서 Vault 연결과 위임을 관리하며 Flow 로그인·선언한 여러 화면·선택형 계정 확인을 제공합니다. 앱·DMG 공증과 세 Mac 설치, 전체 회귀 3,027건 실패·오류0, 설치된 Safari 로그인 Flow/후속 읽기/재사용, 실제 Vault 관리 창과 TextEdit 첫 작업을 확인했습니다. 외부 계정 로그인·MFA·새 사용자 설치·제한 베타를 대신하는 검증은 아닙니다.
[rc.11 검증 결과](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.11)의 VALIDATION.json을 확인하고 실제 사용 결과를 기록하세요.

### 이전 rc.9의 검증 기록

이전 후보는 `v1.0.0-rc.9`(DMG SHA256 `31f322cd09a0c690a95074314434c7386e8ffb652aaf4985108c478012623a5c`)이며 정식 안정 버전이 아닙니다.
검증 중 앱이 바뀌면 담당자에게 알리고 새 후보로 결과를 구분합니다.

rc.9는 Finder의 마지막 창을 닫은 뒤 데스크톱 항목이 목록에 남아 있어도 실제 창이 없음을 정확히 확인합니다. 시스템 설정 작업은 일반 실행 경로로 처리합니다. 문서 범위 세션·창이 많은 화면의 관찰·포인터와 포커스 안정화·첫 작업 복구를 유지합니다.

동일 DMG의 실제 Finder·Safari·TextEdit 작업 **60/60**(창이 많은 Finder 전면 조건), 창 닫힘·지연·대상 변경·Flow 중간 실패 복구 **12/12**, `absent_role: Window`를 지정한 마지막 Finder 창 닫기를 새로 검증했습니다. 마지막 창 닫기는 런타임 종료0과 새 목록의 실제 창0개를 모두 확인했습니다.

rc.8 실제 복귀와 rc.9 복원, 세 Mac의 동일 번들·서명·에이전트 연결·기존 데이터·허용된 권한 보존도 확인했습니다. 전체 회귀 2,977건 실패0·오류0·사유 있는 제외15건이며, 앱·DMG 신규 공증·티켓·Gatekeeper·산출물12개 검사·최종 DMG 보안 점검을 통과했습니다.

독립 성능과 새 에이전트 결과는 별도로 기록합니다. 새 사용자 DMG 설치·권한 변경주기·제한 베타는 이번 자동 시험 범위 밖입니다.
[rc.9 검증 결과](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.9)를 확인하고 실패·개입도 함께 기록하세요.

이전 [rc.8 기록](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.8)의 마지막 Finder 창 닫기 검증 오류는 당시 결과로 보존하며 rc.9의 새 검증과 구분합니다. rc.8 최초 회귀1건 실패·단독27건과 전체 재검 통과, [rc.6 기록](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.6)의 최초 실기59/60·별도 재검60/60, [rc.5 기록](https://github.com/Open330/tacto/releases/tag/v1.0.0-rc.5)의 초기 실패33.59초·별도 성공 실행4.39초도 당시 사실로 보존합니다.

### 설치 및 환경 기록

DMG에서 Tacto를 Applications로 옮긴 뒤 시작 안내에 따라 연결합니다.
Mac·macOS·대상 앱·에이전트와 모델 버전을 기록합니다. 기존 사용자와 새
사용자를 구분하고, 설치 실패나 권한 안내가 이해되지 않는 경우도 보고합니다.

## 3일 동안 할 일

자신이 실제로 맡기려는 작업을 최소 3개 고릅니다. 예를 들어 시험용 폴더의
파일 정리, 공개 웹페이지에서 정보 확인, 소유한 문서의 편집·저장입니다.
처음 작성한 Flow를 입력값만 바꿔 재사용하는 작업도 포함하면 좋습니다.

각 시도에 다음을 기록합니다.

| 항목 | 기록할 내용 |
|---|---|
| 참여자 | 담당자가 부여한 익명 ID |
| 환경 | 후보 태그·DMG SHA256·OS·앱·에이전트·모델 버전 |
| 작업 | 요청한 목표, 처음 실행인지 Flow 재사용인지 |
| 결과 | 성공·실패·불확실, 실제로 확인한 최종 상태 |
| 시간 | 시작·종료 시각 또는 대략적인 소요 시간 |
| 개입 | 창을 앞으로 가져오기, 직접 입력, 재시도 등 사람이 도운 내용 |
| 오류 | 실패 단계·오류 이름·실행 기록 ID와 재현 조건 |

실패 후 이미 저장·전송됐는지 먼저 확인합니다. 불확실한 결과를 성공으로
보고하거나 실패 기록을 지우지 않습니다. 원치 않는 대상 조작·중복 실행·
데이터 손상·정보 노출·설치 불가가 있으면 해당 작업을 멈추고 담당자에게
재현 조건을 전달합니다.

## 실행 기록 공유

Tacto 앱의 실행 기록에서 해당 시도를 확인합니다. 계정명·문서 본문·개인
경로·화면 캡처가 들어갈 수 있으므로 공유할 부분을 먼저 검토합니다.
보고서에는 익명 ID와 오류·단계·기록 ID를 우선 제공하고, 필요한 원본은
담당자가 정한 비공개 경로로만 전달합니다.

## 완료 판단

담당자는 5명의 3일 사용과 각자 3개 이상 작업, 전체 실패 기록을 확인합니다.
출시를 막는 결함이 없어야 베타 항목을 통과로 바꿀 수 있습니다. 자동 검사나
담당자의 반복 실행으로 이 조건을 대체하지 않습니다. 새 사용자 설치와 권한
복구 3회는 [출시 기준](release-readiness.md)의 별도 항목으로 확인합니다.
