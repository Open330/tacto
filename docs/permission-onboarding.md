# 권한 받기 UX — ChatGPT(Sky) 조사와 Tacto 적용

> 현재 이름·화면: 권한용 helper는 **Tacto Helper**, 독립 앱의 화면 기록 주체는 **Tacto**입니다.
> 현재 GUI와 이름 전환의 검증 범위는 [최신 GUI 검토](tacto-gui-review-2026-10-17.md)를 따릅니다.
> 이 문서의 제품명은 현재 표기로 통일했습니다. 아래 측정 기록의 원문 로그를 그대로 옮긴 것이 아닙니다.


2026-10-16. Tacto가 앱을 조작하려면 macOS 권한 두 가지가 필요합니다:
손쉬운 사용(macOS 27: Device Control and Data Access)과 화면 기록. 이 권한은
시스템 설정에서 사람이 직접 켜야 하고, 앱이 대신 켤 방법은 없습니다. 그래서
UX의 목표는 **사람이 할 일을 한 번에 하나만 보여 주고, 끝난 것을 스스로
알아차리는 것**입니다.

## ChatGPT 컴퓨터 사용 앱은 어떻게 하는가

확인한 대상: `~/.codex/computer-use/Codex Computer Use.app`
(`com.openai.sky.CUAService`, 실행 파일 `SkyComputerUseService`). 공개 문서가
아니라 설치된 번들의 Info.plist와 바이너리에 남은 클래스명·UI 문구를 읽은
결과라, 동작 순서의 세부는 추정이 섞여 있습니다.

| 관찰 | 근거(번들 안의 이름·문구) |
|---|---|
| 필요한 권한을 한 창에 행으로 보여 줌 | `PermissionWindowController`, `PermissionRowRegistry`, `PermissionViewState`; "ChatGPT Computer Use needs these permissions to use apps on your Mac." |
| 행마다 이유를 사람의 말로 씀 | "Allows ChatGPT to access app interfaces", "ChatGPT uses screenshots to know where to click", "Allows ChatGPT to see the visuals in apps" |
| 시스템 설정 옆에 붙는 보조 창에서 앱 아이콘을 끌어다 놓게 함 | `SlimCore.SystemSettingsAccessoryWindowView`, `DraggableApplicationView`, `DragHintView`, `SystemSettingsAccessoryWindowDragDelegate` |
| 설정 화면으로 가는 권한과 시스템 대화상자로 묻는 권한을 구분 | `SystemSettingsPrivacyPermission`, `TCCDialogSystemPermission`, `AppleEventsPermission` |
| 권한 전후 상태를 비교해 완료를 감지 | `_nativePermissionBefore`, `_nativePermissionAfter`, `_isAccessibilityGranted`, `_isScreenRecordingGranted` |
| 앱별로 처음 쓸 때 묻고 "항상 허용"을 둠 | "Allow ChatGPT to use …", "Always allow sending to this chat", "Computer Use is not allowed to use the app '…'" |
| 권한 흐름을 분석 이벤트로 수집 | `CodexComputerUsePermissionWindowShown`, `…PermissionRequested`, `…PermissionGrantFinished` |

## Tacto에 적용한 것 (`setup/`)

| 이전 | 지금 |
|---|---|
| 고정된 안내 문단과 버튼 5개 | 권한마다 카드: 이름, 짧은 이유, 허용할 앱과 현재 상태. 자세한 위치는 설정 도우미에서 안내 |
| 매번 **다시 확인**을 눌러야 상태가 바뀜 | **설정 열기**를 누른 뒤에는 자동 감지(1.5초 간격, 최대 3분). 앱으로 돌아오면 한 번 더 확인 |
| 드래그 아이콘이 시작 앱 안에만 있음 | **설정 열기**가 설정을 열고, 시스템 설정 창 옆에 아이콘 도우미 창을 붙임. 권한이 켜지면 ✓를 띄우고 스스로 닫힘 |
| 열자마자 상태를 모름 | 열 때 helper의 권한 상태를 한 번 읽어 이미 켜진 것을 완료로 표시 |
| 화면 기록이 연결 단계 뒤에 따로 있음 | 두 권한이 순서대로 놓이고, 다음에 할 줄을 강조. 둘 다 켜지면 **에이전트에 연결**이 활성화 |

지킨 원칙:

- **요청 없이 바꾸지 않습니다.** 권한 요청, 설정 열기, 스킬 설치는 각자 클릭으로
  시작합니다. 자동으로 하는 것은 helper가 스스로 보고하는 상태를 **읽는 것**뿐입니다.
  이것도 LaunchServices로 helper를 잠깐 실행해 결과 파일만 받는 방식이라, 공유
  파이썬 인터프리터에 권한을 묻지 않습니다.
- **감지는 끝이 있습니다.** 잊힌 설정 창이 helper를 계속 다시 실행하지 않도록,
  감지는 사용자가 누른 권한 하나에 대해서만 3분 안에서 동작합니다.
- **분석 이벤트를 보내지 않습니다.** Sky의 권한 이벤트 수집은 따라 하지 않았습니다.
- **문구는 실제 쓰임과 같게.** 화면 기록은 "접근성 정보만으로 알 수 없는 화면을
  확인할 때 앱 창을 캡처"하는 데 쓰입니다. 권한별로 실제 macOS 평가 대상 앱을 보여 줍니다. 소스 checkout은 두 권한 모두
  Tacto Helper, 독립 실행 앱은 앱 조작은 Tacto Helper·화면 기록은 Tacto.app입니다.

## 아직 남은 것

- **새 Mac에서의 첫 설치 검증.** 현재 Mac에서는 실제 설정 화면, 드래그 대상과
  두 권한 완료를 확인했습니다. 권한이 없는 새 Mac에서 처음부터 끝까지 진행하는
  검증과 비숙련 사용자 테스트는 별도로 필요합니다.
- **앱별 첫 사용 동의.** Sky는 앱마다 처음 쓸 때 묻습니다. Tacto는 지금 작업별
  승인(되돌리기 어려운 동작의 확인)만 있고, 앱 단위 허용 목록은 없습니다.

## 초보자용 드래그 안내 보완

- 버튼은 ‘설정 열기’로 표시해, 클릭만으로 권한이 켜진다고 오해하지 않도록 했습니다.
- 보조 창은 1/2·2/2 단계를 표시하고, 설정에서 찾을 이름 ‘Tacto Helper’가
  Tacto의 권한용 앱임을 설명합니다. 기존 항목이 있으면 스위치만 켜면 됩니다.
- ‘다른 방법 보기’를 눌렀을 때만 Finder에서 앱을 선택하는 버튼과 앱 위치 복사,
  + 버튼의 파일 선택 창에서 위치로 이동하는 설명을 펼칩니다. 클립보드 변경과
  Finder 열기는 해당 버튼을 클릭할 때만 발생합니다.
- 암호·Touch ID·앱 재시작 요청이 뜨면 어떻게 진행하는지 안내합니다.
- 권한 확인이 실패하거나 시간이 지나면 안내를 유지합니다. 오래된 완료 상태로
  연결 버튼이 활성화되지 않으며, 앱 파일이 없을 때는 재설치 방법을 표시합니다.
- 연결 완료 뒤 Claude Code/Codex의 새 대화에서 무엇을 요청할지 안내합니다.

새 Mac에서의 최초 권한 설정과 비숙련 사용자 테스트는
별도 확인이 필요합니다. 오프스크린 확인은 실제 시스템 설정의 드롭 수락을
검증하는 테스트가 아닙니다.

읽기 전용 설치 이미지 안에서 앱을 열면, 먼저 Applications로 옮기도록 안내하고
권한 확인·명령 연결을 시작하지 않습니다. 이미지를 꺼낸 뒤 연결이 끊기는 것을 막습니다.

실제 Tacto로 설정 열기, 도움말 펼침·접기, 위치 복사 피드백, Finder의 도우미 선택과
권한 미완료 시 연결 차단을 확인했습니다. macOS 27에서도 화면 기록
설정은 별도의 Screen & System Audio Recording 화면입니다. 화면 이동이 끝나기 전
Device Control and Data Access를 보고 통합 화면이라고 판단했던 안내는 정정했습니다.
복사된 helper의 화면 기록 권한은 미완료였으며 이를 우회하지 않았습니다.

## 드래그 대상과 놓을 위치 정정

실제 시스템 로그에서 독립 실행 앱의 `ScreenCapture` 평가 대상은 바깥
`Tacto.app`, `Accessibility` 평가 대상은 `Tacto Helper`임을 확인했습니다.
번들 밖에 helper를 두는 소스 checkout은 두 권한 모두 helper로 평가됩니다.
따라서 이전의 ‘두 권한 모두 helper 하나에만’ 안내는 독립 앱에 맞지 않았습니다.

| 실행 형태 | 앱 조작 목록에 추가 | 화면 기록 목록에 추가 |
|---|---|---|
| 소스 checkout 미리보기 | Tacto Helper.app | Tacto Helper.app |
| 독립 실행 Tacto.app | Tacto Helper.app | Tacto.app |

시작 화면의 각 행에 ‘허용할 앱’을 표시하고, 권한 도우미의 실제 드래그 파일·아이콘·
이름·Finder 보기·위치 복사 대상을 함께 바꿉니다. 파란 안내 상자와 방향 화살표는
옆의 시스템 설정 창을 가리킵니다. 앱 이름과 스위치가 나열된 목록의 빈 곳이나
행 사이에 놓으세요. 화면 기록은 **위쪽 ‘화면 및 시스템 오디오 기록’ 목록**이며,
아래의 시스템 오디오 전용 목록과 구분됩니다. 이미 같은 앱이 있으면 스위치만 켭니다.

독립 앱의 화면 기록 권한은 macOS 기준으로 Tacto 앱 번들에 부여됩니다. helper만
화면 기록 권한을 가진다고 주장하지 않습니다. 터미널·공유 Python에 별도 권한을
요청하지 않습니다. 네이티브 입력의 launcher/helper 상호 서명 검증은 유지합니다.
바깥 앱도 identifier + Apple anchor + 실제 서명 팀으로 DR을 고정해 검증합니다.
helper를 별도 사용자 설치 위치에 두어 권한 소유자를 하나로 유지하는 방안은
향후 패키징 개선 항목입니다.

## 창과 작업 도우미의 수명

Tacto는 Dock 아이콘 없이 메뉴 막대에서 실행됩니다. 설정 창은 권한과 에이전트
연결을 관리하며, 창을 닫아도 메뉴 막대에 남습니다. ‘Tacto 설정’ 아이콘의
‘Tacto 열기’를 누르거나 Applications에서 Tacto를 다시 열면 설정 창이 나타납니다.
Dock과 Command + Tab 목록에는 표시되지 않습니다. 설정 창이 다른 창 뒤에 있으면
메뉴 막대에서 다시 열어 주세요. 완전히 종료하려면 메뉴 막대 아이콘의 ‘Tacto 종료’를
선택합니다. 메뉴의 권한 상태는 마지막 확인 결과이며 ‘권한 다시 확인’이나 창 다시
열기로 갱신합니다.

`open -a Tacto --args --background`로 처음 실행하면 설정 창이나 포커스 이동 없이
메뉴 막대에서 시작합니다. 이미 실행 중인 앱을 보통 방식으로 다시 열면 설정 창이
나타납니다. 로그인 시 자동 실행은 별도로 등록하지 않습니다.

작업용 helper는 앱 번들 안에 이미 들어 있습니다. 별도 앱을 직접 만들거나
상시 실행할 필요가 없습니다. 설치된 명령 실행기가 작업마다 helper를 자동으로
시작하고, 서명과 실행 인스턴스를 확인해 연결하며 명령 종료 때 정리합니다.
GUI를 종료해도 설치된 명령으로 작업할 수 있고, 부여된 권한은 유지됩니다.
반면 앱 파일을 삭제하거나 명령이 가리키는 위치를 옮기면 연결을 다시 해야 합니다.

권한 두 개의 완료와 명령·스킬 설치는 서로 다른 상태입니다. GUI는 권한 완료를
‘에이전트 연결 완료’로 표시하지 않습니다. 연결 버튼은 명령·스킬을 설치하는
별도 동작이며, 성공 후에만 완료 안내를 표시합니다.

설정용 아이콘은 슬라이더 모양입니다. 작업 중에만 나타나는 `● Tacto` 표시와
구분되며, 작업 중 표시의 Esc 중단 기능과는 관계가 없습니다.

## 제품 화면과 연결 상태

GUI는 웹과 같은 잉크색·코랄·크림 팔레트와 Tacto 앱 아이콘을 사용하며 밝은 모드와
다크 모드를 지원합니다. 독립 앱 안의 권한용 helper에도 같은 아이콘을 넣되,
서명 식별자와 요구조건은 바꾸지 않습니다.

에이전트 연결 표시는 권한과 별개로 실제 명령 두 개와 Claude·Codex 스킬 링크를
읽어 확인합니다. 이 앱에 연결됨, 다른 Tacto 설치가 연결됨, 연결 누락, 파일 충돌을
구분합니다. 다른 설치가 연결된 경우 버튼은 ‘이 버전으로 연결’이며, 사용자가
누르기 전에는 연결을 바꾸지 않습니다. 권한 확인·연결 처리 중에는 중복 클릭을 막습니다.

‘첫 요청 복사’는 에이전트에 붙여 넣을 Finder 예제를 클립보드에 복사합니다.
복사만으로 앱 조작을 실행하거나 새 대화를 열지는 않습니다. 연결 완료 후 에이전트의
새 대화에서 요청하도록 안내합니다.


## 2026-10-18 업데이트 확인

이 Mac에서 10월 16일 구버전은 접근성이 허용됐지만, 새 Developer ID 서명 후보는
접근성이 허용되지 않은 것으로 보고됐습니다. 직접 비교한 결과 helper의 번들
식별자는 같고 **서명 팀과 designated requirement는 달랐습니다**. 따라서 이 결과는
이름·경로 변경만으로 권한 승계가 실패했다는 증거가 아닙니다. 같은 서명 팀과
요구조건을 유지한 업그레이드의 권한 승계는 별도 검증이 필요합니다.

업데이트 후에는 새 앱이 표시하는 권한 상태를 확인하고, 꺼져 있으면 해당 앱을
설정 목록에서 추가하거나 켜세요. 기존 명령·스킬 연결은 새 앱의 권한을 확인한 뒤
사용자가 연결 버튼으로 변경합니다. 설정의 과거 항목이나 LaunchServices 등록을
자동으로 삭제하지 않습니다.
