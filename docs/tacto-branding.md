# Tacto 이름 전환과 호환성

NLC의 제품 이름을 **Tacto**로 변경했습니다. Tacto는 에이전트가 작성한 computer-use
Flow를 재사용하는 실행 계층입니다. 문서·웹·CLI·에이전트 스킬의 제품 표기를 통일합니다.

| 사용자 접점 | 현재 이름 | 호환성 |
| --- | --- | --- |
| 제품·메뉴 막대 | Tacto / ● Tacto | 재빌드한 실행기에 반영 |
| 명령 | tacto | nlc도 같은 signed launcher를 실행 |
| 에이전트 스킬 | tacto | 설치기가 소유를 확인한 예전 NLC 스킬을 발견 경로 밖에 백업 |
| Python 배포 | tacto-runtime | 기본 import `tacto`, `import nlc` 호환. PyPI의 `tacto`(촉각 시뮬레이터)와 import 이름이 겹치므로 별도 환경에 설치하고 `pip install tacto`는 쓰지 않음 |
| 웹페이지 | sites/tacto/dist | 예전 사이트 README는 새 경로 안내 |

기본 Python namespace는 `tacto`, 서명된 실행기는 `launcher/tacto`, helper는
`helper/Tacto Helper.app/Contents/MacOS/TactoHelper`입니다. GUI 실행 파일도
`TactoSetup`을 사용합니다. 새 환경 변수는 `TACTO_*`가 우선입니다.

기존 `import nlc.*`와 `nlc` CLI는 작은 호환 계층을 통해 같은 구현을 사용합니다.
서명 식별자 `ai.callabo.nlc.*`는 macOS 권한의 보안 식별자이므로 유지합니다.
이 식별자를 표시 이름과 혼동하지 않습니다. 기존 helper 경로·런타임 환경 변수는
호환 경계에서만 읽으며, 팀·서명 요구조건은 환경변수로 바꿀 수 없습니다.

기존 설치의 `nlc/flows`만 존재하면 그대로 읽고, 새 설치는 `tacto/flows`를 사용합니다.
두 저장소가 모두 데이터를 포함하면 기본 경로를 조용히 골라 데이터를 숨기지 않고
명시적 `FlowStore(path=...)` 선택을 요청합니다. import·doctor는 사용자 파일을
이동하거나 덮어쓰지 않습니다.

Preview 1과 이전 설치는 **NLC Helper**라는 이름을 사용합니다. GUI와 doctor는
실제 설치된 앱 이름을 읽습니다. 새 빌드는 **Tacto Helper**를 사용하되 macOS 설정
목록은 이전 이름을 캐시할 수 있습니다. 권한 유지 여부는 실제 업그레이드에서
별도 검증해야 하며 LaunchServices 캐시는 자동으로 지우지 않습니다.
helper 번들 경로(`NLC Helper.app` → `Tacto Helper.app`)와 실행 파일(`NLCHelper` →
`TactoHelper`)은 바뀌었고, 번들 식별자·서명 요구조건만 유지됩니다. 같은 식별자와
요구조건이면 macOS가 권한을 이어 줄 것으로 예상하지만, 실제 업그레이드로 확인되기
전까지는 확정된 사실로 안내하지 않습니다.

`./skill/install.sh`는 `tacto`와 `nlc` 명령을 새 서명 실행기로 연결합니다.
다른 프로그램·스킬은 덮어쓰지 않으며 소유를 확인한 이전 스킬만 백업합니다.

GitHub 저장소 이름도 `Open330/tacto`로 변경했습니다. clone·문서 링크와
Git remote를 새 주소로 갱신했습니다. 저장소 공개와 라이선스 변경은 별도입니다. 과거 측정의 nlc 라벨과 수치는 원본대로 보존합니다.
자동 수리·batch 등 아직 미배포인 개발 버전 기능은 해당 안내에 표시합니다.

Tacto라는 기존 제품과 Python 패키지가 있습니다. 이 변경은 상표·도메인·패키지
사용 가능성이 검증됐다는 의미가 아니며, 외부 서비스와의 제휴를 뜻하지 않습니다.

검증: 새 사용자 설치·이전 스킬 백업·동명이인 프로그램 보존·읽기 전용 확인,
별도 wheel의 두 CLI 동일 동작, 웹 인터랙션·모바일·외부 요청 차단을 확인했습니다.
직접 조작하는 기존 앱 작업을 전부 재평가한 결과나 상표 권리 검증은 아닙니다.

## 앱 아이콘과 메뉴 막대 자산

| 용도 | 파일 |
| --- | --- |
| macOS 앱 아이콘 | `docs/assets/tacto-app.icns` (16–1024 px, 10개 크기) |
| 아이콘 벡터 원본 | `docs/assets/tacto-app-icon.svg` (64 px 이상), `docs/assets/tacto-app-icon-small.svg` (16·32 px) |
| 설정 메뉴 막대 template | `docs/assets/tacto-menu-template.svg` |

- 로고, 워드마크, 파비콘, 탐색 시트, 세 파일과 `.icns`는 모두 `python3 setup/build_brand_assets.py`가 만듭니다. SVG를 직접
  고치지 말고 스크립트 상수를 고친 뒤 다시 생성합니다. `--check`는 렌더링 없이
  추적 중인 SVG가 생성기와 같은지만 확인합니다. 같은 Mac에서 다시 생성하면 `.icns`가
  바이트 단위로 같습니다.
- 마크는 2026-10-17부터 **포인터 t**입니다. 코랄 포인터의 끝이 t 가로획의 시작점을
  찍습니다. 에이전트가 앱을 클릭하면 작성한 경로가 거기서 이어진다는 뜻입니다.
- 아이콘은 잉크(`#1b211c`) 타일 위의 아이보리 *t*와 코랄 포인터입니다. 마크 모양은
  `tacto-logo.svg` 그대로이고, macOS 아이콘 격자(1024 캔버스 안의 824 px 본체)를 따릅니다.
  파비콘도 같은 잉크 타일을 씁니다.
- 16·32 px은 획을 4.2로 굵게 그리는 소형 광학 크기를 씁니다. 포인터를 가로획에서 떼거나
  돌리지 않습니다. 마크를 커서나 작업 중 표시로 쓰지 않습니다.
- 메뉴 막대의 상시 아이콘은 **설정**을 뜻합니다. 두 개의 슬라이더와 속이 빈 손잡이로
  그리고, 채운 점은 쓰지 않습니다. 작업 중 표시 `● Tacto`와 혼동되지 않게 하려는 것입니다.
  검정과 투명도만 쓰므로 `NSImage.isTemplate = true`로 불러야 밝은·어두운 메뉴 막대에서
  시스템이 색을 맞춥니다.
- 번들 ID와 서명 식별자는 바꾸지 않습니다. 아이콘 교체는 권한이나 저장 Flow에 영향을 주지 않습니다.

## 활성 파일명 정리 — 2026-10-18

보고서·문서의 `nlc-` 접두사를 `tacto-`로 바꾸고 README·문서 간 링크와 평가
실행기의 참조를 함께 갱신했습니다. 네이티브 소스 파일도 `TactoHelper.swift`와
`launcher/tacto.swift`로 통일했습니다. 사용하지 않는 이전 온보딩 경로의 README는
제거했습니다. 비교 보고서의 수치·측정 결과는 변경하지 않았습니다.

후속 namespace 이전으로 Python 구현·실행 경로도 Tacto로 바꿨습니다.
이전 import·명령·서명 식별자·설치 경로는 명시적인 호환 경계에만 남깁니다. 비공개 원자료와 과거
Git 커밋의 파일명은 새로운 측정 결과인 것처럼 재작성하지 않습니다.


## 2026-10-18 업데이트 확인

이 Mac에서 10월 16일 구버전은 접근성이 허용됐지만, 새 Developer ID 서명 후보는
접근성이 허용되지 않은 것으로 보고됐습니다. 직접 비교한 결과 helper의 번들
식별자는 같고 **서명 팀과 designated requirement는 달랐습니다**. 따라서 이 결과는
이름·경로 변경만으로 권한 승계가 실패했다는 증거가 아닙니다. 같은 서명 팀과
요구조건을 유지한 업그레이드의 권한 승계는 별도 검증이 필요합니다.

업데이트 후에는 새 앱이 표시하는 권한 상태를 확인하고, 꺼져 있으면 해당 앱을
설정 목록에서 추가하거나 켜세요. 기존 명령·스킬 연결은 새 앱의 권한을 확인한 뒤
사용자가 연결 버튼으로 변경합니다. 설정의 과거 항목이나 LaunchServices 등록을
자동으로 삭제하지 않습니다.
