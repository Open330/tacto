# Tacto 이름과 배포 식별자

Tacto는 에이전트가 작성한 computer-use Flow를 재사용하는 실행 계층입니다.
제품·명령·Python namespace·에이전트 스킬·저장 경로·서명 식별자는 Tacto로 통일합니다.
이전 이름의 명령·import·환경 변수·저장 경로를 런타임 별칭으로 제공하지 않습니다.

| 사용자 접점 | 이름·경로 |
| --- | --- |
| 제품·메뉴 막대 | Tacto / ● Tacto |
| 명령·에이전트 스킬 | `tacto` |
| Python 배포·import | `tacto-runtime` / `tacto` |
| 서명된 실행기 | `launcher/tacto` |
| 권한용 helper | `helper/Tacto Helper.app/Contents/MacOS/TactoHelper` |
| GUI 실행 파일 | `TactoSetup` |
| 번들 ID·서명 식별자 | `ai.callabo.tacto.*` |
| 환경 변수 | `TACTO_*` |
| Flow 저장소 | `<data>/tacto/flows` |
| 랜딩페이지 | `sites/tacto/dist` |

서명 ID 교체는 표시 이름 변경과 다릅니다. 새 서명 배포를 설치한 뒤 macOS에서
접근성·화면 기록 권한을 다시 허용해야 할 수 있습니다. 소스의 ID가 바뀌었다는
이유로 기존 서명 앱이 갱신되거나 권한이 승계된 것으로 판정하지 않습니다.
저장 Flow는 사용자 데이터이며 명령 별칭을 없애기 위해 삭제하지 않습니다.

`./skill/install.sh`는 `tacto` 명령과 지원 에이전트의 `tacto` 스킬을 연결합니다.
다른 프로그램·스킬을 덮어쓰지 않습니다. 저장소는 `Open330/tacto`이며 공개 여부와
라이선스 변경은 별도입니다. PyPI의 동명 촉각 시뮬레이터와 혼동하지 않도록
별도 가상환경에 `tacto-runtime`을 설치하고, `pip install tacto`는 실행하지 마세요.

## 측정 기록의 이름 이전 — 2026-10-20

문서·측정표·비교 arm/case 키·fixture 이름을 현재 Tacto 표기로 이전했습니다.
이는 **라벨과 식별자의 이전이며 재측정이 아닙니다**. 실행 fixture의 입력 문구가
바뀐 경우 현재 manifest의 fixture 해시도 갱신하므로 이전 조건과 같은 condition ID로
묶어 비교하지 않습니다. 토큰·시간·성공률·실패·SKIP
수치와 결과의 한계를 그대로 유지합니다. Git 이력과 무시된 비공개 원시 아티팩트는
새 측정 결과처럼 재작성하지 않습니다. 과거 기록에 표시된 현재 서명 ID도
이름 정규화이며, 당시 바이너리를 이 ID로 다시 서명했다는 증거가 아닙니다.

## 앱 아이콘과 메뉴 막대 자산

| 용도 | 파일 |
| --- | --- |
| macOS 앱 아이콘 | `docs/assets/tacto-app.icns` (16–1024 px, 10개 크기) |
| 아이콘 벡터 원본 | `docs/assets/tacto-app-icon.svg` (64 px 이상), `docs/assets/tacto-app-icon-small.svg` (16·32 px) |
| 설정 메뉴 막대 template | `docs/assets/tacto-menu-template.svg` |

- 로고, 워드마크, 파비콘, 탐색 시트, 세 파일과 `.icns`는 모두 `python3 setup/build_brand_assets.py`가 만듭니다. SVG를 직접
  고치지 말고 스크립트 상수를 고친 뒤 다시 생성합니다. `--check`는 렌더링 없이
  추적 중인 SVG가 생성기와 같은지만 확인합니다. 같은 Mac에서 다시 생성하면 `.icns`가
  바이트 단위로 같습니다.
- 마크는 2026-10-17부터 **포인터 t**입니다. 코랄 포인터의 끝이 t 가로획의 시작점을
  찍습니다. 에이전트가 앱을 클릭하면 작성한 경로가 거기서 이어진다는 뜻입니다.
- 아이콘은 잉크(`#1b211c`) 타일 위의 아이보리 *t*와 코랄 포인터입니다. 마크 모양은
  `tacto-logo.svg` 그대로이고, macOS 아이콘 격자(1024 캔버스 안의 824 px 본체)를 따릅니다.
  파비콘도 같은 잉크 타일을 씁니다.
- 16·32 px은 획을 4.2로 굵게 그리는 소형 광학 크기를 씁니다. 포인터를 가로획에서 떼거나
  돌리지 않습니다. 마크를 커서나 작업 중 표시로 쓰지 않습니다.
- 메뉴 막대의 상시 아이콘은 **설정**을 뜻합니다. 두 개의 슬라이더와 속이 빈 손잡이로
  그리고, 채운 점은 쓰지 않습니다. 작업 중 표시 `● Tacto`와 혼동되지 않게 하려는 것입니다.
  검정과 투명도만 쓰므로 `NSImage.isTemplate = true`로 불러야 밝은·어두운 메뉴 막대에서
  시스템이 색을 맞춥니다.
- 제품 namespace와 서명 식별자는 `ai.callabo.tacto.*`로 통일합니다. 아이콘 자산 변경과 서명 신원 변경은 별도이며, 서명 신원이 달라지면 macOS 권한을 다시 허용해야 할 수 있습니다.

## 2026-10-18 업데이트 확인

이 Mac에서 10월 16일 구버전은 접근성이 허용됐지만, 새 Developer ID 서명 후보는
접근성이 허용되지 않은 것으로 보고됐습니다. 직접 비교한 결과 helper의 번들
식별자는 같고 **서명 팀과 designated requirement는 달랐습니다**. 따라서 이 결과는
이름·경로 변경만으로 권한 승계가 실패했다는 증거가 아닙니다. 같은 서명 팀과
요구조건을 유지한 업그레이드의 권한 승계는 별도 검증이 필요합니다.

업데이트 후에는 새 앱이 표시하는 권한 상태를 확인하고, 꺼져 있으면 해당 앱을
설정 목록에서 추가하거나 켜세요. 기존 명령·스킬 연결은 새 앱의 권한을 확인한 뒤
사용자가 연결 버튼으로 변경합니다. 설정의 과거 항목이나 LaunchServices 등록을
자동으로 삭제하지 않습니다.


## 2026-10-20 문서·웹·스킬 재점검

README 두 언어, 랜딩페이지, 스킬과 설치 안내, 활성 CLI 예시를 재점검했습니다.
랜딩페이지의 이전 이름과 오래된 Preview 2 표기를 정리하고, 다운로드 대상과
같은 Preview 8로 표시합니다. API 문서의 세션·batch·timing 표지도 실제 출력인
`TACTO_*`로 바로잡았습니다.

신규 acceptance·Sky 비교·반복 실행 수리 프롬프트는 현재 `tacto` 스킬과
명령을 호출합니다. acceptance 키는 `finds_tacto`, 비교 arm은 `tacto`로 함께 이전했습니다. 이 수정 뒤 새 모델 비교를 실행한 것은 아니며, 과거
벤치마크의 토큰·시간·성공률을 새 결과로 바꾸지 않았습니다.

샌드박스 오류 문구와 진단용 indicator probe의 메뉴 표시도 Tacto로 수정했습니다.
이 앱 내부 문구와 번들 스킬 변경은 **다음 서명 빌드부터** 반영됩니다.
현재 배포·설치된 Preview 8의 서명 번들은 이 문구 수정으로 교체하지 않았습니다.

검증 결과:

- 문서·설치·브랜딩·비교 실행 정책·반복 benchmark 관련 단위 테스트 **134개 통과**.
- 에이전트를 실행하지 않고 두 제공자의 acceptance 명령 구성, 현재 스킬 호출,
  설치 경로 판정, Sky와의 도구 분리를 확인했습니다.
- 랜딩페이지 기능·반응형·미디어·접근성 검사 **88개 통과**, JavaScript 오류 없음.
  axe-core 4.14.0의 데스크톱·펼친 화면·모바일 검사에서 위반 없음.
- 데스크톱·모바일 스크린샷을 확인하고 자산 생성기의 `--check`와 설치 스크립트
  구문 검사를 통과했습니다. macOS 앱 조작 시나리오를 새로 실행한 결과는 아닙니다.

이 점검의 자동 검사 결과는 당시 범위의 기록입니다. 현재 namespace·서명 ID 이전의
회귀 검증과 새 서명 배포 여부는 별도로 확인해야 하며, 모든 환경에서 개선 여지가
없다는 보장은 아닙니다.

## 전체 namespace 전환 검증

이전 명령·Python import·환경 변수·기본 저장소의 호환 경로를 제거했습니다.
설치기는 Tacto가 소유한 이전 명령·스킬 링크를 삭제하고, 패키징은 출처를 확인한
이전 프로젝트 메타데이터와 명령 래퍼를 제거합니다. 삭제 대상 식별과 회귀
테스트 입력에만 이전 철자가 남습니다. 외부 프로그램의 링크는 보존합니다.

- 개발용 런처·Helper를 현재 Developer ID로 다시 빌드하고 새 식별자로 검증했습니다.
- 독립 실행 앱 후보의 바깥 앱·Helper·런처 서명을 모두 검증했습니다. 번들 안에서
  이전 import·배포 정보·명령 래퍼가 없고, 프로젝트 console entry가 `tacto` 하나임을
  확인했습니다. 작업 환경의 이전 editable 설치 메타데이터도 정리했습니다.
- 신규 설치·이전 링크 제거·외부 링크 보존 관련 테스트 51개 통과.
- Python namespace·설치·저널 등 104개 검사에서 103개 통과·선택 검사 1개 생략.
  실제 wheel 설치 검사는 별도로 실행해 통과했습니다.
- 문서·비교 실행·조건 해시·업그레이드 관련 검사 125개 통과.
- 전체 2,661개 실행은 수정 중 가져온 이전 테스트와 문자열 길이 변경으로
  21실패·8오류·3생략이었습니다. 해당 9개 모듈을 수정 후 새로 실행한
  96개 검사는 모두 통과했습니다. 전체 suite를 최종 상태로 재실행한 기록은 아닙니다.
- 최종 웹 검사 88개 통과, JavaScript 오류 및 세 화면의 axe 위반 없음.

서명 앱 후보는 `reviews/tacto-namespace-migration-20261020/candidate4/Tacto.app`입니다.
이 후보는 개발용 서명 빌드이며 공증·설치·게시하지 않았습니다. 기존 배포·설치된
Preview 8은 이 namespace 전환을 포함하지 않습니다. 새 식별자의 앱으로 교체하면
사용자가 macOS 권한을 다시 허용해야 합니다. 이전 기본 경로의 사용자 Flow는
자동 삭제하거나 이동하지 않으며, 새 기본 경로로의 데이터 이전은 설치 전 별도로
확인해야 합니다.
